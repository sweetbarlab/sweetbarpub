🔧 Corriger la base de données

Cette opération va parcourir tous les jours sauvegardés du mois sélectionné pour tous les bars et corriger les valeurs Qt Restante fin journée incorrectes (forcées à 0 par l'ancien bug).

⚠ La correction se base sur la règle : si Qt Chargée > 0 et Qt Restante fin = 0 alors Qt Restante fin = Qt Restante veille + Qt Chargée (stock non vendu). Si Qt Chargée = 0 alors Qt Restante fin = Qt Restante veille.
